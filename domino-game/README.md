# فطيس — لعبة دومينو أونلاين

مشروع سيرفر (Node.js + Socket.IO) للعبة الدومينو الخاصة بك، بثلاثة أوضاع لعب (فريقين / فردي مع سحب / فردي بدون بلاطة صفر-صفر).

## تشغيل محلي (لتجربة اللعبة على جهازك)

يتطلب تثبيت [Node.js](https://nodejs.org) (نسخة 18 فما فوق).

```bash
cd domino-game
npm install
npm start
```

بعدها افتح المتصفح على: `http://localhost:3000`

### 🔑 مفتاح الأدمن (مهم جدًا)

عشان **بس أنت** تقدر تنشئ غرفة جديدة (ومنع أي شخص عنده الرابط من إنشاء غرف)، اللعبة تطلب "مفتاح أدمن" سري عند إنشاء أي غرفة.

- **افتراضيًا** المفتاح هو: `change-me-1234` — **لازم تغيّره** قبل ما تنشر اللعبة، وإلا أي حد ممكن يخمّنه.
- لتغييره، عيّن متغيّر بيئة (Environment Variable) باسم `ADMIN_KEY` بالقيمة اللي تبيها (سر خاص فيك بس).
- محليًا على جهازك:
  ```bash
  ADMIN_KEY="سرك_الخاص_هنا" npm start
  ```
- على Render (بعد النشر): من صفحة الخدمة → **Environment** → **Add Environment Variable** → المفتاح `ADMIN_KEY` والقيمة سرّك الخاص → احفظ (سيعيد النشر تلقائيًا).

اللاعبون والمتفرجون ما يحتاجون هذا المفتاح إطلاقًا — فقط عند الضغط على "إنشاء غرفة جديدة".

## الاستضافة على الإنترنت (مجانًا) — الطريقة الموصى بها: Render.com

عشان أصدقاءك يقدروا يدخلون من أي مكان (مو بس شبكتك المحلية)، لازم ترفع المشروع على استضافة حقيقية. أسهل خيار مجاني:

### الخطوات:

1. **أنشئ حساب GitHub** (إذا ما عندك): https://github.com/signup

2. **ارفع المشروع على GitHub:**
   - أنشئ مستودع (Repository) جديد فاضي باسم مثلاً `domino-game`
   - من جهازك، داخل مجلد المشروع:
     ```bash
     git init
     git add .
     git commit -m "أول رفعة"
     git branch -M main
     git remote add origin https://github.com/USERNAME/domino-game.git
     git push -u origin main
     ```
   (أو ببساطة اسحب وأفلت الملفات عبر واجهة GitHub الموقع مباشرة، بدون أوامر)

3. **أنشئ حساب على Render:** https://render.com (تسجيل الدخول عبر GitHub مباشرة أسهل شي)

4. **من لوحة Render:**
   - اضغط **New +** → **Web Service**
   - اختر المستودع (`domino-game`) اللي رفعته
   - الإعدادات:
     - **Environment:** Node
     - **Build Command:** `npm install`
     - **Start Command:** `npm start`
     - **Instance Type:** Free
   - اضغط **Create Web Service**

5. بعد دقيقة أو دقيقتين، Render بيعطيك رابط مثل:
   `https://domino-game-xxxx.onrender.com`

   هذا الرابط هو اللي ترسله لأصدقائك (أو تحطه بقروب الواتساب) للدخول على الغرفة.

### ملاحظة عن الخطة المجانية في Render
الخطة المجانية "تنام" السيرفر لو ما فيه نشاط لمدة ~15 دقيقة، وأول طلب بعدها ياخذ 30-60 ثانية عشان "يصحى". هذا طبيعي وما يأثر على اللعب بعد ما يشتغل. لو تبي سيرفر يفضل شغال دائمًا بدون تأخير، فيه خطط مدفوعة رخيصة (~7$ شهريًا) تشيل هذا التأخير.

## كيف تُستخدم اللعبة

1. الأدمن (أنت) يفتح الرابط، يكتب اسمه، يختار وضع اللعب، يضغط **"إنشاء غرفة جديدة"**
2. يظهر **كود الغرفة** (6 أحرف) — انسخه أو استخدم زر **"نسخ رابط الدعوة"** من لوحة الأدمن وأرسله بقروب الواتساب
3. كل من يفتح الرابط أو يكتب الكود يقدر ينضم كلاعب (لو فيه مقعد فاضي) أو كمتفرج
4. لو أحد دخل كمتفرج بالغلط (أو المقاعد ما توزعت صح)، الأدمن يقدر يضغط زر **"أضفه كلاعب ▶️"** بجانب اسمه بلوحة "المتفرجون" عشان ينقله لأول مقعد فاضي
5. لما يكتمل عدد اللاعبين المطلوب للوضع المختار، الأدمن يضغط **"بدء الجولة"**
6. الأدمن يقدر يعيّن أدمن ثاني من الحاضرين، وبعد انتهاء أي مباراة يقدر يخرج الخاسر(ين) ويسمح بدخول لاعبين جدد

## ما لم يُنفَّذ بعد (للمرحلة القادمة)

- **الشات الصوتي** داخل اللعبة (WebRTC) — تم الاتفاق على تأجيله؛ لحد الآن الأصدقاء يتواصلون صوتيًا عبر قروب واتساب أو مكالمة منفصلة أثناء اللعب.
